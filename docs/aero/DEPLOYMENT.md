# Deployment

There is no supported production deployment yet. Run locally with `npm install` and `npm run dev`. Configure `AI_BASE_URL`, `AI_API_KEY`, and `AI_MODEL` only for a trusted local test. `AERO_DATA_DIR` and `AERO_KNOWLEDGE_ROOT` set local storage locations.

Authentication, tenant boundaries, hardened provider egress, production database/storage services, deployment infrastructure, migrations, and secret management must be completed before deployment.
